
<REPO_DIR> devcontainer control.   Backend follows the active docker context.
Local engine builds bind-mount this folder. The remote engine clones the repo into a volume on EC2.
Second column: both = works on either engine via the active context, local/remote = that engine only,
host = runs on this machine and touches no engine at all.

START HERE
  make up                 both    Get working from any state: refreshes the tunnel (remote), builds or starts as needed, then opens VS Code.

FIRST RUN  once per machine
  make init               host    Create the gitignored config files (incl. the hostcreds manifest) from their examples. Never overwrites an existing one.
  make keybindings        host    Bind Shift+Enter to a newline in VS Code terminals. Must run on the host, not in the container.

ENGINE  pick where builds and containers live
  make local              host    Point docker and VS Code at the local engine (<LOCAL_DOCKER_CONTEXT>). Nothing remote is stopped.
  make disconnect         host    What 'make local' calls. Only changes where new commands and windows point.

INSTANCES  one remote engine per project under remote-instances/; instance names are project names (e.g. brimbooks), never geographies or stages
  make list-instances     host    List every instance with live status: EC2 state, id, params, certs, forward, context.
  make instance-init      host    Scaffold <project>'s directory; never deploys. INSTANCE=<instance-name> [AMI=] [REGION= for the AMI/AZ lookup only; the deployment region is REMOTE_AWS_REGION]
  make instance-deploy    remote  Converge: provision, link id, trust chain if missing, push secrets. Refuses instance replacement without CONFIRM=replace. INSTANCE= | ALL=1
  make instance-status    host    One instance's live state, or every instance with ALL=1. INSTANCE=<instance-name> | ALL=1
  make instance-plan      remote  Terragrunt plan per instance; bootstraps the shared state bucket on first run. INSTANCE=<instance-name> | ALL=1
  make instance-stop      remote  Stop the EC2 instance and wait until it reports stopped. INSTANCE=<instance-name> | ALL=1
  make instance-start     remote  Start it again and wait for its SSM agent to report ready. INSTANCE=<instance-name> | ALL=1
  make instance-destroy   remote  Destroy + cleanup params, certs, context, id. CONFIRM=destroy only for ALL=1. INSTANCE=<instance-name> | ALL=1
  make instance-link      host    Save the instance's EC2 id for other targets. Deploy does this automatically; run it only after re-provisioning outside make. INSTANCE_ID=<id>
  make cert-ca            host    Create this instance's certificate authority. Once per instance; refuses if one exists.
  make cert-client        host    Issue the client certificate 'make connect' presents. Run after cert-ca, and again at renewal.
  make cert-publish       remote  Issue server material and publish it to Parameter Store. The daemon needs it to open its listener.
  make cert-install       remote  Have the instance fetch the published material and start its daemon. Run after cert-publish.
  make cert-status        host    Client and CA expiry per instance.
  make push-secrets       remote  Publish shell.env and aws-profile-map.json to Parameter Store. Remote builds do this when needed.
  make connect            remote  What 'make remote' calls. Opens the forward for INSTANCE=<name> (or ENGINE=<name>); re-run after a reboot, after sleep, or when SSO expires.
  make remote             host    Point them at the EC2 engine (<REMOTE_DOCKER_CONTEXT>), refreshing the SSM port forward first. INSTANCE=<name> targets that instance.

BUILD  every target blocks until the container is up and exits non-zero if anything fails
  make build              both    Create the container for the active backend. Refuses if one already exists.
  make rebuild            both    clean, then build. Prerequisites are checked before anything is destroyed.
  make build-no-cache     both    build with the image rebuilt from scratch.
  make rebuild-no-cache   both    rebuild with the image rebuilt from scratch. Use when a feature or base image changed.
  make clean              both    Destroy the container, its private volumes and its image. Shared volumes and the base image are kept.

LIFECYCLE
  make status             both    Backend, container, image and volumes. Read-only, so start here when something looks wrong.
  make reopen             both    Open the container in VS Code. Local opens the folder; remote names the container to attach to.
  make exec               both    Interactive shell inside the container. CONTAINER_SHELL picks which one.
  make vscode-server      both    Fetch the VS Code server this machine needs inside the container. reopen does it for you.
  make start / stop       both    Start or stop the container. The checkout survives either way.
  make restart            both    Restart in place. Fixes a wedged container without rebuilding anything.
  make rename NAME=x      both    Give the container a readable name. New ones are <repo>-<devcontainerId>, which is too long to pick from a list.
  make check              both    Remote: report uncommitted or unpushed work in the volume, non-zero when dirty. Local: a no-op, the container shares this folder.

SECRETS AND CERTIFICATES
  make push-creds         both    Resolve every hostcreds manifest entry on this machine and push it into the container. Git entries also seed ~/.git-credentials.
  make creds-init         host    Prompt once per missing keychain item the hostcreds manifest names and store it. CREDS_INIT_ARGS='--stdin NAME' feeds one value from stdin.
  make verify-container   both    Check the pushed credentials inside the container: fragment modes, startup block, git and aws reachability.

HOST PROXY  only needed behind a corporate proxy; remote builds force HOST_PROXY=false
  make proxy-start        local   Run tinyproxy on this machine. Local containers reach it via host.docker.internal.
  make proxy-status       local   Whether it is running, and on which port.
  make proxy-restart      local   Stop then start, picking up changed settings.
  make proxy-stop         local   Stop it. Settings come from .devcontainer/remote-docker/config.env; set HOST_PROXY=true in shell.env to make the container use it.

QUALITY
  make lint               host    Private files untracked, no nested repos, no host venv in the workspace, JSON parses, shellcheck, markdown, US English, staged secrets. Non-zero on any finding.
  make lint-secrets       host    Scan staged content for secrets, or RANGE=<a>..<b> for a commit range. Exit 1 on any finding; there is no ignore list.
  make format             host    Auto-fix what the markdown tooling can fix, then report what is left.
  make lint-spell         host    US English spelling over this repo's markdown. SPELL_FILES overrides the set.
  make spell-fix          host    Auto-fix spelling, British-to-American included, in the same set. Rewrites the files.
  make hooks-install      host    Install pre-commit and pre-push hooks via devcontainer_config.githooks. Refuses to clobber a hook it did not write.
  make hooks-run          host    Exactly what pre-commit runs. Use it to reproduce a pre-commit failure.
  make hooks-run-push     host    Exactly what pre-push runs: lint, then a secrets scan of every commit in the pushed range.
  make test               host    Run the hermetic pytest suite in tests/. No docker, no AWS, no network.
  make validate           host    The green-baseline contract automation depends on. Runs lint then test.

SKILLS  wire this repo's .agents/skills roster into an agent on this Mac; no devcontainer involved
  make skills-install     host    Wire an agent to the canonical skills home: global symlink (default), project verify/wire, or the runtime one-shot incantation (printed, never run). AGENT=opencode|claude|both SCOPE=global|project|runtime
  make skills-remove      host    Delete only a general-dev-skills symlink resolving inside this repo; refuses everything else. AGENT=opencode|claude|both SCOPE=global|project|runtime
  make skills-list        host    Show each agent scope: installed (target), native (project), or not installed. AGENT=opencode|claude|both SCOPE=global|project|runtime

OPTIONS
  ENGINE=local|<name>             Address one engine explicitly (ENGINE=x make <target>, or make <target> ENGINE=x): parallel terminals can drive local and remote engines concurrently, without switching contexts. Unset follows the active context.
  CONTAINER=<name>                Pick one instance when several clones of this repo exist. 'make status' lists them.
  FORCE=1                         Proceed past the unpushed-work and uncommitted-config guards.
  SKIP_SECRETS_CHECK=1            Do not compare shell.env against Parameter Store, and do not publish it.
  NO_CACHE=1                      What the no-cache targets set. Works with build and rebuild directly.

PREREQUISITES
  container targets       docker
  remote engine           aws, session-manager-plugin, and the instance id recorded by instance-deploy (make instance-link)
  build and rebuild       devcontainer CLI, git, jq, python3      npm install -g @devcontainers/cli
  lint                    uv                                      brew install uv
  test                    uv, zsh                                 uv: brew install uv   zsh: brew install zsh (macOS) or sudo apt-get install -y zsh (Linux, WSL)
  Every target checks what it needs and fails with the command that installs it.
