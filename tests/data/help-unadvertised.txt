# .PHONY targets deliberately not advertised by `make help`, one entry per
# line as `<target>: <reason>`. tests/test_help_snapshot.py fails the
# correspondence assertion (AC-FUNC-003) if a `.PHONY` target is neither
# advertised, a prerequisite of an advertised target, nor named here with a
# non-empty reason -- and fails again (AC-TEST-004) if an entry's reason is
# empty, so a target cannot be hidden from `make help` without a recorded
# reason.

help: this is the target `make help` itself renders; advertising itself in its own output would be circular and would add a row that does nothing a developer does not already know from having typed it.

hooks-uninstall: part of the bypass surface the PreToolUse hook denies (spec Section 4.6.1); advertising it in `make help` would advertise the bypass it exists to deny.
