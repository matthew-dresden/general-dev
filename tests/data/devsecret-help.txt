usage: devsecret [-h] {get,list,set,rm,run,export-list} ...

Read and write the secret catalog (spec Section 4.3).

positional arguments:
  {get,list,set,rm,run,export-list}
    get                 get <NAME>: print one value on stdout. Nothing else.
    list                list [--scope <scope>]: names, scopes, last-changed,
                        exported flag. Never prints a value.
    set                 set <NAME> [--scope <scope>] [--exported]: read the
                        value from stdin. Never from an argument.
    rm                  rm <NAME> --scope <scope>: delete after confirmation.
    run                 run --secrets A,B -- <cmd>: run <cmd> with only those
                        secrets in its environment.
    export-list         export-list: names marked exported, for shell startup.

options:
  -h, --help            show this help message and exit

scopes:
  shared                        Every engine and instance.
  <instance>                    One environment. Resolved before shared.

exit codes:
  0 success   2 usage   3 backend unreachable or unauthorized
  4 not found 5 refused because a value would have been exposed
